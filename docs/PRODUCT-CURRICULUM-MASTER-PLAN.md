# JD-Xi Tutorial Hub — Product & Curriculum Master Plan

**Status:** Authoritative v1 planning baseline  
**Course size:** 30 canonical guided tutorials — B01–B10, N01–N10, I01–I10  
**Target instrument:** Owner's Roland JD-Xi running System Program 1.51  
**Runtime:** Static HTML/CSS/JS, direct `file://`, desktop only

---

# 1. Product definition

The JD-Xi Tutorial Hub v1 is a **beginner-to-intermediate guided learning app**, not a complete encyclopedia of every JD-Xi feature.

Its primary purpose is to make the owner comfortable enough with the instrument to:

- operate it confidently;
- find and shape sounds;
- understand Programs and Parts practically;
- create drum and bass patterns;
- combine multiple Parts into a groove;
- use important performance controls;
- save and organize useful Programs;
- create a polished multi-part looping groove/pattern;
- perform over and manipulate that groove without someone walking them through the JD-Xi.

A later version may expand toward a more comprehensive JD-Xi reference/learning system if v1 proves useful enough, but **v1 is intentionally bounded**.

---

# 2. Owner and firmware target

v1 is designed for **one owner and one known physical JD-Xi**, not as a universal firmware-adaptive training product.

Target hardware evidence:

- JD-Xi System Program: **1.51**, owner-observed.
- 1.10 and 1.50 feature additions are therefore available.
- 1.52 is not required for tutorial behavior.

Settings should display:

> **Tutorial target: JD-Xi System 1.51**

# 3. Course philosophy

## 3.1 Learner assumptions

Assume:

- no synthesizer experience;
- no music-theory background;
- no need to learn note names, scales, chords, intervals, rhythmic notation, or formal synthesis theory;
- the learner succeeds by seeing, touching, listening, comparing, and repeating.

## 3.2 Teaching loop

Default instructional loop:

**Do → see → hear → optional practical context**

Rules:

- one primary action per step by default;
- concise primary instruction;
- detail hidden/secondary;
- observable checkpoint;
- recovery help on every step;
- no forced “Got it”/quiz interaction;
- no traditional quizzes;
- no XP, badges, streaks, scores, or gamification;
- `Why?` is used sparingly for practical/safety context only, not synthesis theory.

## 3.3 No theory curriculum

The app does **not** teach:

- note names;
- scales;
- chord names;
- intervals;
- music notation;
- formal rhythm theory;
- ADSR diagrams;
- filter-frequency theory;
- synthesis electronics.

Where musical language is unavoidable, use practical phrases such as:

- “a low key that sounds good”;
- “a nearby key”;
- “hold two or three keys”;
- “faster / slower”;
- “straighter / swingier”;
- “shorter / longer”;
- “brighter / darker”.

# 4. v1 completion outcome

Course completion means the learner can independently:

1. choose a Part and find a Tone;
2. play and manipulate sounds;
3. use Pitch, Mod, Octave, Transpose, Arpeggiator, Tap Tempo, Part Mute, Program changes, and live effects where appropriate;
4. make a basic drum beat;
5. make a bass line;
6. combine Parts into a loop;
7. use TR-REC and Step Recording;
8. correct sequencer steps;
9. extend a pattern toward the JD-Xi's four-measure maximum where useful;
10. shape useful bass, pad, and lead sounds;
11. build a four-Part performance Program;
12. create a fuller groove with a fill/variation;
13. save and name the Program safely;
14. register it as a JD-Xi hardware Favorite;
15. load it and perform/manipulate it live.

The final target is **a polished looping groove/pattern that can be performed over and manipulated live**, not a full multi-section arranged song.

# 6. Curriculum progression model

The course uses a **hybrid project structure**.

## Beginner

Mostly independent experiences. The purpose is confidence and first-hand familiarity.

## Novice

N04–N06 deliberately form a short creation sequence:

- N04: simple drum beat;
- N05: simple bass line;
- N06: simple multi-Part loop.

However, this sequence is designed so it can be **recreated quickly** and does not depend on saving between lessons.

No later lesson assumes that Novice work still exists on the instrument.

## Intermediate

Intermediate starts a **fresh final project**.

- I07: assemble a four-Part performance Program;
- I08: build the fuller groove/pattern;
- I09: save and organize it;
- I10: perform it.

This project is the final v1 capstone experience.

---

# 7. Direct-entry and state-safety contract

Every guided tutorial remains clickable at all times.

Prerequisites are advisory, never gates.

Therefore no tutorial may assume:

- a particular Program;
- a particular Tone;
- a clean edit buffer;
- prior course completion;
- a saved project from an earlier tutorial;
- an empty user destination;
- a fixed startup Program.

Any action that can discard unsaved work must use the established **protect-your-work preflight**.

The preflight must:

- state plainly what could be lost;
- warn the learner before the state-changing action;
- never claim a destination is safe/empty;
- never claim there is a universal undo;
- direct the learner to N09 when saving knowledge is needed.

# 8. Beginner curriculum master allocation

## B01 — Meet your JD-Xi

**Role:** Silent orientation baseline.

**Owns:** whole-instrument orientation; keys; Part Select; sound-selection controls; sound-shaping sections; pattern controls; display; Master Volume; rear panel; power area.

**Does not own:** operation, sound changes, connections, menu navigation, sequencing.

## B02 — Get your first sound

**Role:** Safe first audible success.

**Owns:** listening-path setup; power-on sequence; Master Volume safety; choose Digital Synth 1; play first sound; comfortable listening level.

**Does not own:** Program browsing, Tone exploration, synthesis, patterns, saving.

## B03 — Find sounds you like

**Role:** Teach sound browsing by ear.

**Owns:** Tone browsing; Category + Tone −/+; choosing sounds by ear; comparing several Tones within a Part.

**Defers:** Program browsing as a complete-setup concept; Program architecture; saving; deep Tone structure.

**Safety:** Tone changes that can discard unsaved edits require protect-your-work wording.

## B04 — Meet the four parts

**Role:** Make all four Parts concrete through sound.

**Owns:** Digital Synth 1, Digital Synth 2, Drums, Analog Synth; selecting and playing each; hearing differences; one selected Part plays from keys; Drums Part maps different drum sounds across keys.

**Does not own:** Program architecture, synth-engine theory, sequencing, detailed drum programming.

## B05 — Play with the keys

**Role:** Explore performance controls without theory.

**Owns:** low vs high; one vs several keys; short vs held; Octave Down/Up; Pitch; Mod; Transpose phrased as shifting the whole keyboard higher/lower.

**Does not own:** note names, intervals, scales, chord theory, formal keyboard technique.

**Portamento:** Quick Reference only; optional later enrichment from I03.

## B06 — Change the sound with knobs

**Role:** First ear-driven sound shaping.

**Owns:** Cutoff; Resonance; AMP/ENV Envelope; LFO Rate/Depth; one obvious Analog control only if useful; dramatic ear-first changes; safe experiment/reselect recovery.

**Defers:** waveform architecture, Sub OSC, Pulse Width, formal filter/envelope/LFO theory.

## B07 — Add effects

**Role:** Hear simple effect changes.

**Owns:** Reverb; Delay; one simple Effect 1/2 example; dry vs effected comparison; ear-based choice.

**Does not own:** effect algorithm taxonomy, deep effect routing, detailed Effect 1/2 study.

## B08 — Play a pattern

**Role:** Make preset pattern playback understandable.

**Owns:** start/stop; recognize 01–16 row; switch Part Select while playing; hear/inspect Parts; Part Mute; Program changes to hear different preset patterns where useful; Part Mute as early arranging concept.

**Safety:** Program browsing requires unsaved-work warning.

## B09 — Change the feel

**Role:** Change groove feel without rhythmic theory.

**Owns:** Tempo knob; Tap Tempo; Shuffle; faster/slower; straighter/swingier.

**Does not own:** sequencer Scale, rhythmic subdivision, notation.

## B10 — First 15-minute challenge

**Role:** Beginner graduation.

Minimal hand-holding challenge: pick Part → find sound → play → alter → add effect → start pattern → change tempo/feel → mute/unmute.

# 9. Novice curriculum master allocation

## N01 — Learn the menu controls

Already integrated/frozen. Owns the established safe Menu/Cursor/Enter/Exit/SYSTEM/Shift concepts and display-provenance rules.

## N02 — Understand programs and parts

**Role:** Practical complete-setup mental model.

**Owns:** practical Program definition; Program contains four Parts plus pattern/effect-related state; keys play one selected Part; Program Value changes complete Program; Part Select changes played/edited Part; switch among Programs and compare; Program changes can discard unsaved edits; recall a hardware Favorite.

**Does not own:** saving, Favorite management, deep Program Edit.

## N03 — Sequencer basics

**Role:** Establish two working entry methods without a full beat.

**Owns:** 16 numbered buttons operationally; start/stop; select Part; enter TR-REC; lit/unlit steps; add/remove one step; correct/erase one step; pattern length relationship; introduce TR-REC and Step Recording as different note-entry methods.

**Does not own:** full beat, bass line, Realtime Recording, Pattern Copy, Scale/subdivision.

## N04 — Make a simple drum beat

**Role:** First authored rhythmic content.

**Owns:** select Drums Part; choose usable kit; identify kick/snare/closed hi-hat by pressing keys; TR-REC; place kick/snare/hat; listen; correct one step; one small actual drum-sound edit; finish with a simple one-measure beat.

**Defers:** deep drum-kit editing, velocity/accent, long patterns, fills, saving.

## N05 — Make a simple bass line

**Role:** First authored pitched sequence.

**Owns:** suitable synth Part; bass Tone; TR-REC; hold/play a key and enable steps; alternate nearby key on selected steps; listen with beat; correct/remove note; brief Step Recording alternate; low-key practical bass guidance.

**Language:** “pick a low key that sounds good,” not root/scale/note-theory terms.

## N06 — Combine parts in a pattern

**Role:** First multi-Part groove.

**Owns:** recreate simple drums+bass; add Digital Synth 1; add Digital Synth 2 or Analog; simple sequence entry; Part Mute to audition combinations; muting/unmuting as arranging tool; finish with a simple loop.

**Requirement:** minimum 3 Parts; fourth optional.

**Defers:** full four-Part project, keyboard “layering,” full song arrangement, save dependency.

## N07 — Try the arpeggiator

**Role:** Make Arpeggiator usable without theory.

**Owns:** choose synth Part; Arpeggiator on; hold 2–3 keys; change keys; style; range; tempo; use over pattern; create one useful arpeggiated layer; turn it off cleanly.

**Depth:** enough to use deliberately later.

## N08 — Edit a sound more deliberately

**Role:** Bridge random tweaking to intentional sound design.

**Owns:** existing Tone; brighter/darker; shorter/longer; smoother/sharper; still/moving; dry/spacious; intentional LFO; intentional effect amount; before/after; safe reselect/recovery.

**Does not own:** deep oscillator architecture or synthesis theory.

## N09 — Save your work

**Role:** First safe persistence lesson.

**Owns:** create a small disposable practice edit inside N09; invoke WRITE; name; select user destination; explicit overwrite understanding; learner chooses a destination they are willing to overwrite; confirm; never power off while writing; verify completion; switch away and return if source-supported; optional register saved Program as hardware Favorite.

**Never:** nominate a supposedly empty slot; imply universal rollback; teach backup/restore; require Tone-saving workflow.

## N10 — Getting unstuck

**Role:** Small recovery toolkit, not a troubleshooting tree.

**Owns:** Exit/back out where documented; recognize top screen; Exit does not undo saved/auto-saved actions; context-specific sound revert shortcut; Program changes can discard unsaved edits; Factory Reset is destructive and not routine; Quick Reference links.

**Primary safety shape:** N10 must remain safe to open while the learner is already stuck and may be carrying unsaved work. Its main recovery path is therefore recognition-first and must not force a state-changing demonstration.

**Optional final practice:** after the recovery toolkit has been taught, N10 may offer a small sound-edit + documented `[Shift] + [Enter]` revert exercise **only after an explicit protect-your-work decision**. The learner must be told to skip the exercise if the currently loaded sound contains edits they want to keep. This optional exercise must not be required to complete N10.

**Does not:** deliberately enter a harmless menu just to practice recovery; force a Program change; perform Factory Reset/Restore.

# 10. Intermediate curriculum master allocation

## I01 — Build a bass sound

**Role:** First useful custom sound.

**Owns:** appropriate existing bass Tone; best engine/Part for teaching; oscillator/waveform only as needed; cutoff/resonance; amp/envelope; optional sub/analog control; movement only if useful; finish with usable bass inside current Program.

**Target:** broad “solid/deep bass,” not exact recipe.

## I02 — Build a pad sound

**Role:** Sustained background texture.

**Owns:** suitable Digital starting Tone; longer attack/release; smoother/darker filter; gentle LFO; Reverb/Delay; octave/register choice; finish with pad that sits behind other Parts.

No chord theory. “Hold several keys if you want to hear the texture fill out.”

## I03 — Build a lead sound

**Role:** Playable foreground sound.

**Owns:** suitable starting Tone; brighter/more focused filter; faster envelope; Pitch/Mod; Delay/Reverb; optional Portamento via Quick Reference; finish with live-playing lead.

## I04 — Filter and envelope shaping

**Role:** Comparative practical lab.

**Owns:** one existing sound; make three contrasting versions; change cutoff/resonance/envelope; hear soft/plucky/bright/short/etc.; restore/reselect; choose controls deliberately for a practical sound goal.

**Does not own:** filter-frequency theory or ADSR diagrams.

## I05 — LFO and movement

**Role:** Comparative movement lab.

**Owns:** one sound; LFO Rate/Depth; slow vs fast movement; sparing modulation; combine with Mod where useful; finish with one moving texture.

**Does not own:** every LFO destination or exhaustive parameters.

## I06 — Effects and space

**Role:** Practical effect balancing in groove context.

**Owns:** Reverb; Delay; Effect 1; Effect 2; too dry/useful/too much; compare bass vs pad vs lead; back effects down for groove clarity.

**Does not own:** algorithm taxonomy, deep effect study, Side Chain Compressor.

---

# 11. Final Intermediate project

## I07 — Build a multi-part program

**Role:** Start the final project fresh.

Frame: **Build your performance groove setup.**

**Owns:** choose/shape Drum kit; bass; pad/chord-like synth; lead/arpeggio synth; sensible effects; audition Parts; assemble all four in one Program; only minimal test pattern if needed.

## I08 — Build a fuller pattern

**Role:** Deepest sequencer lesson and final groove construction.

**Owns:** use I07 Program; build drum groove; bass; synth Part; fourth Part; extend pattern gradually; work toward four measures; four measures are a goal not hard requirement; fill/variation by changing final steps; Part Mute for arrangement audition; Step Recording where useful; correct steps; deeper drum editing.

**Does not own:** Realtime Recording, Pattern Copy, Scale/subdivision, velocity/accent, full multi-section song arrangement.

## I09 — Save and organize creations

**Role:** Turn final groove setup into reusable personal Program.

**Owns:** safe Program save; meaningful name; intentional overwrite destination; verify save; register as hardware Favorite; practical organization workflow.

**Does not own:** Tone-saving curriculum; backup/export/import; maintenance; Pattern Copy; Program copying/reorganization by default.

## I10 — Performance challenge

**Role:** Course capstone.

Using the saved I07–I09 creation: load; start pattern; mute/unmute Parts; Tempo/Tap Tempo; Pitch; Mod; Octave/Transpose where suitable; Arpeggiator if suitable; adjust effect live; play one selected Part over pattern; stop cleanly.

Use several appropriate performance tools, not every control regardless of fit.

Successful completion of I10 = **Course Complete**.

# 31. Source-authority contract

Technical procedure remains governed by official Roland sources.

Before a new technical step becomes authoritative, verify:

- exact hardware operation;
- menu/parameter names;
- button sequence;
- save behavior;
- sequencer behavior;
- firmware applicability;
- display state.

Source precedence:

1. newest applicable supplementary manual;
2. Owner's Manual;
3. Parameter Guide;
4. MIDI Implementation only for MIDI-specific claims.

Third-party content does not establish technical procedure.

Do not invent display strings.

---

# 32. Display house rule

A tutorial/reference may reproduce a display screen Roland illustrates.

It may not compose/invent a screen.

For non-synthetic displays:

- `syntheticDisplay: false`;
- `displayNote` required;
- source/evidence recorded;
- variable fields identified.

The current ≤16-character-per-line check remains a guard only, not a claim that the display is 16×2.

---

# 33. Destructive-risk contract

Never casually teach Factory Reset, Restore, firmware update, destructive clearing, overwrite, or Program change after unsaved edits.

Rules:

- warnings before destructive action;
- no nominated “safe” destination;
- no universal undo language;
- SYSTEM auto-save behavior described truthfully;
- never power off during write/restore/update;
- destructive Quick Reference entries remain explicit.

Factory Reset and Restore are not normal v1 guided exercises.
